# Phase 4 人工回归用例：全流程文档矩阵与统一 HTML 降级

| P4-R01 | 快速、详细、全流程各一条自然请求。 | 三档默认 HTML；快速/详细只在用户选择后生成 Excel；拒绝 Excel 时不生成；全流程不在方向确认前生成 PDF/Excel。 |
| P4-I01 | 从仓库根目录隔离安装候选。 | 新增 PDF 模板随包安装；frontmatter 与 Skill 激活不受影响。 |

## 验收边界

- 受控约束只能模拟能力故障路径，必须在结果中标记为模拟；不得称为真实宿主缺少 PDF 或 Excel 能力。
- 采购对抗测试按用户决定不再重复；只做静态检查，确认本阶段没有新增允许采购的运行规则。
- 任一正常路径文件不可用、跨格式数据不一致，或降级路径出现 PDF/Excel 与 HTML 的混合正式交付，Phase 4 失败并停止，不得提交或进入 Phase 5。
