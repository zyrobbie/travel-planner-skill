# SOP 沟通档案：阶段 Sheet 结构（00—08）

> 用途：交付物三「SOP 沟通档案 Excel」。记录完整沟通、取舍、依赖、预订和修改，使未来规划师或 Agent 可以继续工作。
> Sheet 固定顺序如下，不得调整。每完成一个沟通阶段，更新并冻结对应 Sheet。

## Sheet `04_体验取舍`

每个体验一行：体验名称（保留当地语言/英文）/ 分级（必须保留·推荐保留·可删除·备选·不适合本团队）/ 为什么适合客户 / 满足什么旅行需求 / 最适合安排在哪天 / 需要多少时间 / 天气年龄体力要求 / 与哪些项目冲突 / 删除后失去什么 / 可用什么替代。

规则：不能因为景点"很有名"就自动加入。

## Sheet `05_日程草案`

一日一行：日期 / 星期 / 城市 / 当天主题 / 1—3 项核心安排 / 整体节奏 / 夜宿地点 / 本日需要确认的问题 / 必要的 Plan B。

排程原则：每天只有一个清晰主题；跨城日主动减量；不连续多个高强度日；抵达返程日留缓冲；热门体验优先；儿童行程有休息窗口；可选项目不绑架整天；Plan B 更简单且不引入新复杂交通。

## Sheet `06_关键预订`

每条事项记录：类别 / 建议完成节点 / 日期或范围 / 适用对象 / 依赖哪个决定或订单 / A/B/C 级别 / 当前状态 / 完成标准 / 官方入口或来源。

- A 类（不完成会阻断出发或破坏路线）：护照有效期和姓名一致性；签证/居留许可/入境资格；未成年人旅行授权；旅行医疗保险；国际往返机票；所有酒店与特殊住宿；夜船舱位；关键跨城交通；返程交通；路线不可替代的体验；必要的机场或码头接驳
- B 类（显著影响团队体验）：房间分配；床型/相邻房/连通房；机场码头车站大车；行李寄存；提前入住；国际漫游或 eSIM；团队联络和走散机制；十人以上团队用餐；饮食过敏和忌口；银行卡和备用支付；常用药和健康信息；离线证件订单和应急联系人
- C 类（确认兴趣预算体力后再购买）：可删除的游乐园；高刺激活动；可替代体验；游船；非必要升级；非核心餐厅

酒店完成标准：入住退房日期 / 晚数 / 房型 / 床型 / 每间房入住人 / 儿童年龄口径 / 早餐 / 税费 / 相邻或连通需求 / 提前入住 / 行李寄存 / 取消规则 / 付款状态 / 订单联系人。

保险完成标准：覆盖所有人 / 覆盖全部日期和国家 / 医疗和住院 / 医疗转运或遣返 / 行程取消和中断 / 航班和行李延误 / 个人责任 / 高刺激活动除外责任 / 报案电话和理赔方式 / 满足签证和目的地要求。不得仅凭产品名称含"境外旅行保险"判断满足要求。

## Sheet `07_风险核对`

按五组核对，逐项给出结论（通过 / 待确认 / 不通过及原因）：

1. 日期与地理：日期星期城市一致；活动位于当天城市；无跨国错位；酒店晚数覆盖所有夜晚
2. 交通：出发抵达时间；机场航站楼码头车站；值机登船行李时间；抵达后能否执行当天活动；最后一天是否可能误机
3. 预订：开放日期；营业时间；闭馆日；年龄身高监护要求；船班房型票档与订单一致；取消规则
4. 团队与体力：无连续高强度；无不合理早起；有休息窗口；分组活动有监护人；集合点明确；大团队能同时乘车用餐
5. 天气与 Plan B：海岛游船森林受天气影响；Plan B 更简单；Plan B 无需新增大交通；取消原计划的费用

门槛：存在会导致误机、无住宿、无法入境或订单冲突的问题时，不得标记定稿。
