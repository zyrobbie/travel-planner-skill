# 客户简明版 Excel 结构

## 档位与生成时机

- **快速**：仅在 HTML 已生成并检查、客户明确需要 Excel 后生成一份最小用户版；允许 1—4 张真正有用的用户 Sheet，例如每日行程、预算、出发前核对、官方来源。未知内容写“待确认”“未提供”或“不适用”；不得生成空 Sheet 或内部 SOP。
- **详细**：仅在 HTML 已生成并检查、客户明确需要 Excel 后生成一份用户版；默认使用下列 `一页总览`、`每日行程`、`预订清单` 三张用户 Sheet。必要来源可放在既有字段中，不得加入空表或内部 SOP 内容。
- **全流程策划**：保留本模板的三张客户简明版 Sheet 与既有 SOP 档案流程；不因本节缩减原有全流程交付。

生成任何 Excel 前后都不得臆造日期、订单、价格、库存或已完成采购状态。必须用独立表格工具打开、渲染每张非空 Sheet 并人工检查中文、表头、换行、列宽、链接、公式错误、空白和异常分页；不通过不得交付。

## 中文字体兼容性

- 中文工作簿优先不显式指定单一操作系统专属字体；允许使用主题字体、默认字体和表格软件的中文字体回退机制。
- 不建议主动把中文限定为只面向拉丁字符的字体，但字体名称本身不是单独的通过或失败条件。
- 最终判断以真实表格软件的结果为准：文件能否打开，中文标题、表头和正文是否完整，是否出现乱码、空白、碎片化或严重截断，以及公式、链接和跨交付数据是否正确。
- 如真实表格软件显示异常，再更换字体、取消显式字体或调整样式。未测试的平台只记录为兼容性风险，不得宣称全部平台通过。
- 不得为兼容性把字体文件打包进 Skill，且不得破坏一句话安装结构。

> 用途：交付物一。让客户在 3 分钟内理解路线、节奏和下一步行动。
> Sheet 数量服务于易用性：不得为满足数量创建空表，也不得把快速档扩张为内部档案。

## Sheet 1 `一页总览`

| 字段 | 内容 |
|------|------|
| 旅行日期 | [起止日期] |
| 团队构成 | [人数、成人儿童年龄、家庭构成] |
| 城市路线 | [城市顺序 + 停留晚数] |
| 整体旅行主调 | [一句话] |
| 整体强度 | [轻松/适中/偏高] |
| 五条核心旅行主线 | [5 条，各一句话] |
| 当前最先确认的事项 | [按优先级列 3—5 项] |
| 简洁可视化路线 | [简图或路线字符串] |

## Sheet 2 `每日行程`

一日一行，字段固定为：

| 日期 | 城市 | 当天主题 | 核心安排 | 节奏 | 夜宿 | 需要确认 |
|------|------|----------|----------|------|------|----------|

## Sheet 3 `预订清单`

标题可显示为"关键预订与出发准备"，字段固定为：

| 类别 | 建议完成时间 | 事项 | A/B/C 级别 | 当前状态 | 完成标准 | 官方依据或入口 |
|------|--------------|------|------------|----------|----------|----------------|

## 客户版禁止出现

- 大量内部推理
- 机器处理字段
- 订单号
- 护照号
- 证件照片
- 支付信息
- 每个普通景点单独占一行
- 十几张 Sheet
