# 全流程 PDF 固定版式行程文档

> 用途：仅供全流程策划的分享、打印、留档与固定版式阅读。PDF 面向旅行者，不是内部 SOP。

## 生成时机与来源

客户确认 HTML 行程方向后，先冻结最终主行程。优先从已确认的最终 HTML 或同一份冻结主行程生成真实 `.pdf`，避免内容分叉；若主行程随后修改，必须同步重新生成并检查 HTML、PDF 和两个 Excel。

PDF 至少包含：旅行概览与团队信息、路线与城市顺序、每日行程与节奏、重点体验、住宿与交通建议、关键预订及 A/B/C 优先级和状态、风险与 Plan B、待确认事项、官方来源、版本与生成日期。

不得包含支付资料、证件号码、订单创建信息、内部推理或未标明的推测。

## 文件与版式要求

- 必须是真实 PDF，不得把 HTML 改扩展名。
- 中文完整显示；无空白页、乱码、内容覆盖或严重截断。
- 表格不得超出页面；标题不得单独留在页尾；正文字号、页码、页面顺序和打印边距可正常阅读。
- 链接必须可识别；条件允许时保留可点击链接。

## 真实验收

正式交付前必须完成：文件类型与非空检查、页数检查、文本提取检查、全部页面渲染为图片并逐页人工视觉检查，以及与 HTML 和两个 Excel 的日期、团队约束、城市、住宿晚数、每日安排、体验、交通、预订、风险、待确认事项、来源和版本核对。

PDF 无法可靠生成、打开、提取或逐页检查时，不得列为正式交付；按 `html-delivery.md` 统一降级为完整 HTML，且不同时正式交付任何 Excel。
